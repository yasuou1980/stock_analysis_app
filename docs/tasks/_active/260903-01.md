# 260903-01 ベースレート超過(エッジ)を実績レポートの主要指標にする

## Goal

勝率の隣に「同期間・同ユニバースで何もしなかった場合の勝率」を併記し、その差(エッジ)を主要指標として出力する。

## Files

リポジトリルート: `stock_analysis_app`

- `signal_tracker.py:213` (`compute_onset_performance` 冒頭の終値パネル生成を共通化)
- `signal_tracker.py:280` (`summarize`)
- `signal_tracker.py:343` (`write_report`)
- `tests/test_signal_tracker.py`

## Changes

1. `_price_panel(hist) -> pd.DataFrame` を `compute_onset_performance` の直前に新設。
   中身は `compute_onset_performance` 内の既存パネル生成をそのまま移す:
   `hist.pivot_table(index="signal_date", columns="ticker", values="close", aggfunc="last").sort_index().apply(adjust_for_splits)`
   （`hist["signal_date"]` は `pd.to_datetime` 済みにしてから渡す）。
   `compute_onset_performance` はこの関数を呼ぶよう置換する。

2. `compute_base_rates(hist, horizons=HORIZONS) -> dict[int, dict]` を新設。
   各 n について `fwd = panel.shift(-n) / panel - 1` を `.stack().dropna()` し、
   `{n: {"n": 件数, "up_rate": 100*(v>0).mean(), "avg_pct": 100*v.mean()}}` を返す。
   `hist` が空、または全 horizon で値が取れない場合は `{}` を返す。

3. `summarize` の各レコードに4列を追加する。`compute_base_rates` の結果を引数
   `base_rates: dict | None = None` で受け取り、None の場合は4列とも `np.nan`。
   - BUY:  `base_win_rate = up_rate`,        `base_avg_pct = avg_pct`
   - SELL: `base_win_rate = 100 - up_rate`,  `base_avg_pct = -avg_pct`
   - 共通: `edge_win_rate = win_rate - base_win_rate`, `edge_avg_pct = avg_pct - base_avg_pct`
   （`fwd_{n}d` は SELL で符号反転済みのため、比較対象のベースも反転させる）

4. `write_report` で `base_rates = compute_base_rates(hist)` を計算し `summarize` に渡す。
   戦略別テーブルの列を差し替える(中央値は落とす):
   ```
     シグナル  日数  件数    勝率   ベース   エッジ     平均  平均エッジ
     BUY       10d    58   58.6%   52.0%   +6.6pt   +3.60%    +1.98pt
   ```
   ヘッダ直下の注記に1行追加:
   `※ ベース = 同期間・全銘柄の単純保有。エッジ(勝率差/平均差)がプラスで初めて価値がある`
   既存の【ロジック版別実績】【ゲートで抑制されたシグナルの成績】【直近N日】は変更しない。

5. `base_rates` が空 dict のときは従来どおり勝率・平均・中央値の3列で出力する
   (履歴が浅くフォワード値が無い場合にレポート生成を落とさない)。

## Tests

`tests/test_signal_tracker.py` に追加。合成データは「A は毎日上昇 / B は毎日下落」で作り、
全 5 日先リターンが A は正・B は負になるようにする。

- `test_compute_base_rates_splits_evenly`: 上記データで `compute_base_rates(hist, (5,))[5]["up_rate"] == 50.0`
- `test_summarize_edge_buy`: BUY の `base_win_rate` が `up_rate` と一致し、
  `edge_win_rate == win_rate - base_win_rate`
- `test_summarize_edge_sell_inverts_base`: SELL の `base_win_rate == 100 - up_rate`
  かつ `base_avg_pct == -avg_pct`
- `test_summarize_without_base_rates_keeps_nan`: `base_rates=None` で4列が NaN、既存列は不変
- `test_write_report_contains_edge_columns`: 生成テキストに `ベース` と `エッジ` を含む
